# Chapter Zero · Elements collection

Eight supporting SVG shapes and three repeatable SVG patterns, each in four brand treatments. SVG shapes have transparent backgrounds. Patterns have a colored background and a seamless repeating tile.

These are original supporting elements, not replacements for the supplied logo. Preserve proportions; use one primary motif and treatment per composition. Do not place essential small text directly over patterns. Green and orange elements are decorative; all live text still follows the main contrast rules.

## Shapes
- **The opening:** An open arch gives a headline, book, or photograph a place to begin.
- **The turned page:** A single softened page with a folded corner. Use as a quiet content container.
- **The bookmark:** An editorial marker for a reading list, saved idea, or recurring series.
- **The conversation:** Two offset speech panels express a meeting of perspectives.
- **The handoff:** A continuous pair of directional paths. Use for exchange and circulation.
- **The thought line:** An expressive reading line. Keep it beneath text rather than through it.
- **The margin marks:** Open editorial brackets draw attention without enclosing the whole conversation.
- **The shared shelf:** A rhythm of book spines for collections, lists, and shared reading.

## Patterns
- **Shelf rhythm:** A calm repeat for broad backgrounds and printed endpapers.
- **Margin grid:** A fine editorial grid for working surfaces and notes.
- **Conversation field:** An open pattern for community chapter dividers.

## React components
Import from src/components/BrandKit.jsx and include brand-kit.css. Include the Sora font and site color variables, or define your own matching base styles. BrandShape also needs src/brand-elements.js. This kit uses React and lucide-react. See component-catalog.md for props and behavior.
