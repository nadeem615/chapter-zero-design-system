# Chapter Zero brand system

Open **Chapter Zero Brand Guide.html** in a browser for the visual reference. It works offline and links to the original logo asset, so keep this folder beside `New folder`. Print to PDF from the browser with background graphics enabled for a portable reading copy.

- **Chapter Zero Brand System.md** — editable source of the complete brand rules.
- **Chapter Zero Brand Guide.html** — formatted guide with four creative composition studies, palette, type specimens, and calculated contrast table.
- **design-tokens.json** — reusable color, type, spacing, radius, and motion values.
- **design-tokens.css** — CSS variables and sample action styles.
- **contrast-audit.csv** — calculated text and boundary contrast checks.
- **build_brand_guide.py** — standard-library-only builder; run `python "Brand System/build_brand_guide.py"` from the parent folder after editing the Markdown.

Sora is specified by the original identity but font files were not supplied or bundled. Install Sora from its official project for accurate font rendering; Arial is the explicit fallback. The original PNG files remain unchanged. See the guide for the vector master and native-template production work still needed.

This release is tailored to the founder-confirmed online book community. New positioning, voice, and operational design rules are proposed standards, while original colors, Sora guidance, tagline, and logo artwork come from the supplied files.
